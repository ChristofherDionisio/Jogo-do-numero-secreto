<h1>JOGO DO NÚMERO SECRETO</h1>

<h2>Sobre</h2>

<p class="texto-justificado";>O intuido deste projeto é o desenvolvimento de um jogo divertido que pode ser jogado com a família e amigos, o objetivo do jogo consiste em descobrir um número secreto que é sorteado aleatóriamente, o ganhador é a primeira pessoa que conseguir acertar este número.
Este é um projeto realizado no decorrer do curso de lógica de programação da Alura e que ainda se encontra em desenvolvimento, pois no decorrer do curso estaremos implementando novas funcionalidades e mecânicas que deixaram o jogo ainda mais divertido.</p>
